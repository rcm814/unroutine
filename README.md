# Unroutine

Unroutine is a mobile-first yoga and mobility app designed around one idea: training should adapt to the day you actually have.

The first MVP is a guided flow experience with pose cues, timed movements, progress tracking, and simple session navigation.

## Current MVP

- Guided yoga + mobility flow
- Automatic pose timer
- Start / pause controls
- Previous / next movement navigation
- Session progress indicator
- Pose focus + coaching cues
- Hip and T-spine starter flow
- Responsive mobile-first interface

## Tech stack

- React
- Vite
- JavaScript
- CSS

## Run locally

```bash
git clone https://github.com/rcm814/unroutine.git
cd unroutine
npm install
npm run dev
```

Then open the local URL Vite prints in your terminal.

## Product direction

Planned additions include:

- Session generator by duration and focus
- Larger pose database
- Pose illustrations
- Full-lotus progression programming
- Voice cues and transitions
- Weekly training planner
- Saved sessions and progress history
- Gym workout generator
- Meal generator

## Why Unroutine?

Most fitness apps either present a static exercise library or prescribe a rigid program. Unroutine is intended to generate practical training sessions around the user's available time, workload, and mobility goals.
